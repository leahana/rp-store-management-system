# 数据库表设计

本项目包含以下四个主要表：用户表、店铺表、评论表、商品表。每个表的设计及其之间的关系如下：

## 1. 用户表 (users)

| 字段名     | 类型     | 描述                                |
| ---------- | -------- | ----------------------------------- |
| id         | INT      | 用户ID (主键)                       |
| username   | VARCHAR  | 用户名                              |
| email      | VARCHAR  | 用户邮箱                            |
| password   | VARCHAR  | 用户密码                            |
| role       | VARCHAR  | 用户角色 (如普通用户、店铺管理员等) |
| created_at | DATETIME | 创建时间                            |
| updated_at | DATETIME | 最后更新时间                        |

## 2. 店铺表 (shops)

| 字段名      | 类型     | 描述                            |
| ----------- | -------- | ------------------------------- |
| id          | INT      | 店铺ID (主键)                   |
| shop_name   | VARCHAR  | 店铺名称                        |
| owner_id    | INT      | 店铺管理员ID (外键，指向用户表) |
| description | TEXT     | 店铺描述                        |
| created_at  | DATETIME | 创建时间                        |
| updated_at  | DATETIME | 最后更新时间                    |

## 3. 评论表 (comments)

| 字段名       | 类型     | 描述                      |
| ------------ | -------- | ------------------------- |
| id           | INT      | 评论ID (主键)             |
| user_id      | INT      | 用户ID (外键，指向用户表) |
| shop_id      | INT      | 店铺ID (外键，指向店铺表) |
| comment_text | TEXT     | 评论内容                  |
| rating       | INT      | 评分 (如1到5星)           |
| created_at   | DATETIME | 创建时间                  |
| updated_at   | DATETIME | 最后更新时间              |

## 4. 商品表 (products)

| 字段名       | 类型     | 描述                      |
| ------------ | -------- | ------------------------- |
| id           | INT      | 商品ID (主键)             |
| shop_id      | INT      | 店铺ID (外键，指向店铺表) |
| product_name | VARCHAR  | 商品名称                  |
| price        | DECIMAL  | 商品价格                  |
| description  | TEXT     | 商品描述                  |
| created_at   | DATETIME | 创建时间                  |
| updated_at   | DATETIME | 最后更新时间              |

## 表关系

1. **用户与评论**：
   - 用户可以发表评论。评论表中的 `user_id` 与用户表中的 `id` 相关联，表示评论由哪个用户发出。

2. **用户与店铺**：
   - 用户可以是店铺的管理员。店铺表中的 `owner_id` 与用户表中的 `id` 相关联，表示店铺的所有者。

3. **店铺与评论**：
   - 评论是针对店铺的。评论表中的 `shop_id` 与店铺表中的 `id` 相关联，表示评论属于哪个店铺。

4. **店铺与商品**：
   - 每个店铺可以拥有多个商品。商品表中的 `shop_id` 与店铺表中的 `id` 相关联，表示商品属于哪个店铺。
